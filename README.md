[Andmeinseneeria kursuse](https://github.com/KristoR/ut-andmeinseneeria-2026) grupitöö eesmärgiks oli luua terviklik andmelahendus, mis integreerib turundusinvesteeringud (Google Ads – edaspidi plaanitud ka Meta Ads), veebianalüütika (Google Analytics 4), CRM-i müügivihjed ja tellimused ning iseteeninduse lepingute andmed ühtseks täheskeemil põhinevaks andmemudeliks. Nii saab täpsemalt hinnata turundusinvesteeringute tasuvust.
